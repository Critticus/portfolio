Project 2 - Portfolio Website

Dit project focust op het ontwerpen en ontwikkelen van een persoonlijke portfolio website binnen het vak webtechnologie. Het doel was om mijn projecten op een duidelijke en professionele manier te presenteren, terwijl ik de aangeleerde technieken uit de lessen kon toepassen in een realistische context.

Tijdens dit project heb ik de structuur van de website opgebouwd met HTML, waarbij ik gebruik heb gemaakt van semantische elementen om de inhoud logisch en overzichtelijk te organiseren. Voor de vormgeving heb ik CSS gecombineerd met Bootstrap, waardoor de website een consistente layout heeft en correct weergegeven wordt op verschillende schermgroottes.

Daarnaast heb ik verschillende pagina’s aangemaakt en gekoppeld via een navigatiesysteem, zodat gebruikers eenvoudig door de website kunnen navigeren tussen de verschillende projecten en informatie. Ook heb ik gewerkt met componenten zoals afbeeldingen, knoppen en formulieren om de inhoud visueel aantrekkelijk en gebruiksvriendelijk te maken.

Tijdens het ontwikkelen heb ik mijn website regelmatig getest in de browser en aangepast waar nodig, zodat alle onderdelen correct functioneren en de gebruikerservaring optimaal blijft. Dit zorgde ervoor dat de uiteindelijke website stabiel, overzichtelijk en professioneel is opgebouwd.

Dit project heeft mij inzicht gegeven in hoe een website van begin tot eind wordt opgebouwd, en hoe verschillende technologieën samenwerken om een functioneel en aantrekkelijk eindresultaat te realiseren.
